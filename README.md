# 3D-CAD MCP Suite (8-in-1 Model Context Protocol Bridges)

Open-source **Model Context Protocol (MCP)** server suite connecting **Claude Desktop / Claude Code** and MCP clients directly to professional 3D DCC, CAD, and game engine software:

1. **Autodesk 3ds Max 2026 (3dsmax-mcp)** - TCP socket + MaxScript / Python scene graph, modifier stack, rigging, and batch FBX/glTF pipeline automation.
2. **Maxon ZBrush (zbrush-mcp)** - ZScript + file-watcher bridge for automated high-poly sculpting operations, ZRemesher, Decimation Master, and UV Master.
3. **Adobe Substance 3D Painter (substance-painter-mcp)** - Python remote scripting bridge for smart material assignment, PBR texture baking, and UE5 preset export.
4. **Autodesk Maya (maya-mcp)** - CommandPort TCP bridge for Python/MEL rigging, HumanIK retargeting, and animation curve tools.
5. **Autodesk AutoCAD (autocad-mcp)** - COM / ActiveX (pywin32) bridge for 2D/3D CAD drafting, layer management, and DWG/DXF geometry generation.
6. **Blender & Unreal Engine 5 Bridges** - Direct Python/C# pipeline synchronization for indie game studios and technical artists.
